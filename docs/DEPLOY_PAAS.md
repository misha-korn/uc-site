# Деплой без своего сервера (без nginx и certbot)

Платформа сама собирает сайт из GitHub по `Dockerfile`, выдаёт домен с HTTPS и перезапускает
сайт после каждого `git push`. Ничего настраивать на сервере не нужно.

| | Amvera (amvera.ru) | Render (render.com) |
|---|---|---|
| Для чего | рабочий сайт заказчика и постоянное демо | быстрое бесплатное демо |
| Данные | в России (важно для 152-ФЗ) | за рубежом |
| Цена | от 170–290 ₽ в месяц | бесплатно |
| Диск | постоянный (`/data`) | временный: при перезапуске база создаётся заново |
| Сон | нет | засыпает через 15 минут без посетителей, просыпается ~1 минуту |
| Домен | `<проект>.<логин>.<регион>.amvera.tech` + свой домен | `<имя>.onrender.com` + свой домен |

## Amvera — пошагово

1. Регистрация на amvera.ru, пополнить баланс (оплата картой РФ).
2. «Создать проект» → тип «Приложение» → тариф «Начальный» → способ загрузки «Через GitHub»
   (или «Через Git»: Amvera даст адрес, добавьте его командой
   `git remote add amvera <адрес>` и отправляйте `git push amvera master`).
3. Конфигурация уже в репозитории — файл `amvera.yml` (сборка по Dockerfile, диск `/data`, порт 8000).
4. Вкладка «Переменные» (секреты — в «Секреты»):

   | Переменная | Значение |
   |---|---|
   | `SECRET_KEY` (секрет) | длинная случайная строка: `python -c "import secrets;print(secrets.token_urlsafe(50))"` |
   | `DEBUG` | `0` |
   | `ALLOWED_HOSTS` | `.amvera.tech` (плюс свой домен через запятую, если подключён) |
   | `SITE_URL` | полный адрес сайта, например `https://uc-site.misha.ru1.amvera.tech` |
   | `DATABASE_URL` | `sqlite:////data/db.sqlite3` |
   | `MEDIA_ROOT` | `/data/media` |
   | `USE_X_FORWARDED_FOR` | `1` |
   | **только демо:** `SITE_DEMO` | `1` (плашка «демо», запрет индексации) |
   | **только демо:** `SEED_DEMO` | `1` (загрузить демо-данные при запуске) |
   | **только демо:** `DEMO_VIEWER_PASSWORD` (секрет) | пароль гостевого входа `demo` в панель (только просмотр) |
   | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_CHAT_ID`, `EMAIL_*` | по желанию — уведомления о заявках |

5. Вкладка «Домены» → «Добавить доменное имя» → HTTPS → «Бесплатный домен Амвера».
   Сертификат выпускается автоматически (несколько минут). Свой домен — там же, «Свой домен»
   (A-запись + TXT `_amvera`).
6. Первый вход в панель: вкладка «Консоль» проекта (или переменная `DEMO_ADMIN_PASSWORD` на демо) →
   `python manage.py createsuperuser`.
7. Обновление сайта — просто `git push`: платформа пересоберёт и перезапустит сайт,
   база и файлы в `/data` сохраняются.

**Бэкап:** раз в неделю скачивайте `/data` через вкладку «Данные» (база + документы).

## Render — бесплатное демо за 5 минут

1. render.com → вход через GitHub → **New → Blueprint** → репозиторий `uc-site`.
   Настройки возьмутся из `render.yaml`.
2. Заполнить `SITE_URL` (адрес вида `https://uc-site-demo.onrender.com`) и `DEMO_VIEWER_PASSWORD`.
3. Через 5–10 минут сайт открыт по адресу `*.onrender.com`.

Перед показом заказчику откройте сайт сами, чтобы он «проснулся».

## Рабочий сайт заказчика (чек-лист)

- `SITE_DEMO=0`, `SEED_DEMO=0`, `DEMO_VIEWER_PASSWORD` пустой.
- Свой домен заказчика, `ALLOWED_HOSTS` и `SITE_URL` под него.
- Реальные реквизиты и документы с ЭП внесены через панель, демо-данные удалены.
- Уведомление в Роскомнадзор об обработке ПДн подано заказчиком.
