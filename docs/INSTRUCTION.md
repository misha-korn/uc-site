# Инструкция для учебного центра: как вести сайт

Эта памятка для сотрудника, который будет обновлять сайт. Программировать не нужно: всё меняется в панели управления.

## 1. Вход в панель
1. Откройте в браузере `https://адрес-вашего-сайта/admin/`.
2. Введите логин и пароль, которые выдал разработчик. Пароль никому не пересылайте в мессенджерах.
3. Слева два раздела: **«Сайт»** (направления, программы, заявки) и **«Сведения об образовательной организации»**.
4. Чтобы изменить запись, щёлкните по ней, поправьте поля и нажмите **«Сохранить»**. Дата обновления на странице сайта поменяется сама.
5. Поле **«Порядок»**: чем меньше число, тем выше запись на странице.

## 2. Где заполняется каждый подраздел «Сведений»
Раздел «Сведения об образовательной организации» обязателен по приказу Рособрнадзора № 1493. Сведения нужно обновлять в течение 10 рабочих дней после любых изменений.

| Подраздел на сайте | Что открыть в панели |
|---|---|
| Основные сведения | Основные сведения об организации (одна запись), Учредители, Места осуществления образовательной деятельности |
| Структура и органы управления | Структура и органы управления: у каждого подразделения поле «Положение о подразделении (файл)» |
| Документы | Документы, раздел «Документы» (устав, правила, локальные акты, отчёт о самообследовании) |
| Образование | Программы обучения (файлы программы, учебного плана и т. д.), Документы и Текстовые сведения с разделом «Образование» |
| Образовательные стандарты | Текстовые сведения и Документы с разделом «Образовательные стандарты и требования» |
| Руководство | Руководство (директор и заместители) |
| Педагогический состав | Педагогический состав (у каждого преподавателя отметьте его программы) |
| Материально-техническое обеспечение | Материально-техническое обеспечение (кабинеты, площадки, библиотека), Текстовые сведения (доступная среда, ЭОР, общежитие), Документы (перечень ЭОР) |
| Платные услуги | Документы (положение, образцы договоров, приказ о стоимости). Цены берутся из программ |
| Финансово-хозяйственная деятельность | Текстовые сведения: финансовый год, объёмы, поступление и расходование средств. Документы: план ФХД или смета |
| Вакантные места | Вакантные места: по каждой программе |
| Стипендии, Международное сотрудничество, Питание | Текстовые сведения с соответствующим разделом |

**Если сведений нет** (нет общежития, договоров с иностранными организациями, столовой), не удаляйте запись, а напишите «Отсутствует» или «Не предусмотрено». Робот Рособрнадзора проверяет, что пункт есть на странице.

Поле **itemprop** — служебная метка для робота проверки. Выбирайте её из подсказок и не меняйте у существующих записей.

## 3. Как загрузить документ с электронной подписью
1. Подготовьте PDF **с текстовым слоем**: текст в нём должен выделяться мышью. Скан-картинка без распознавания не подходит.
2. **Подпишите документ заранее, до загрузки.** Сайт сам подпись не ставит. Варианты:
   - усиленная квалифицированная подпись (УКЭП) руководителя, например через КриптоПро PDF;
   - простая электронная подпись по вашему локальному акту (положению об ЭП): в PDF ставится отметка «Документ подписан простой электронной подписью», ФИО, должность и дата.

   Какой вариант выбрать и как его оформить, решает организация. Разработчик сайта юридических гарантий здесь не даёт, при сомнениях уточните у юриста.
3. В панели: **Документы → Добавить документ**. Заполните раздел, itemprop, понятное название («Устав АНО ДПО …»), номер и дату, загрузите файл (до 20 МБ).
4. Галочка **«Подписан электронной подписью»**, поле «Кто подписал» и дата подписи — это **только отметка на сайте** о том, что файл подписан. Ставьте её, только если файл действительно подписан.
5. Сохраните, откройте страницу на сайте и проверьте, что ссылка открывает файл.

## 4. Заявки
1. **Сайт → Заявки.** Новые заявки сверху, статус «Новая». Если настроены почта или Telegram, придёт уведомление «Новая заявка №…» без личных данных.
2. Откройте заявку, позвоните клиенту, поменяйте статус на «В работе», затем «Обработана». Заметки пишите в поле «Заметка менеджера».
3. **Выгрузка в Excel:** отметьте нужные заявки галочками, вверху выберите действие **«Экспорт в CSV (Excel)»** и нажмите «Выполнить».
4. Спам отмечайте действием «Отметить как спам». Старые заявки, которые больше не нужны, обезличьте действием «Удалить персональные данные»: так требует закон о персональных данных.

## 5. Как убрать программу с сайта
Откройте **Сайт → Программы обучения**, выберите программу и снимите галочку **«Опубликована»**. Программа исчезнет из каталога и из «Сведений», но останется в панели, её можно вернуть. Чтобы убрать программу с главной, снимите галочку «Популярная (показывать на главной)».

## 6. Перед запуском сайта: проверить обязательно
- [ ] **Удалить все демо-данные:** вымышленные программы, преподавателей, документы с надписью «ДЕМО-ДОКУМЕНТ», заявки. Отключить плашку «Демо-версия» (это делает разработчик: `SITE_DEMO=0`).
- [ ] **Вписать реальные реквизиты:** полное название, адрес, ИНН, ОГРН, номер и дату лицензии, телефоны, e-mail, учредителя, руководство.
- [ ] **Загрузить настоящие документы**, подписанные электронной подписью (см. п. 3).
- [ ] **Подать уведомление в Роскомнадзор** об обработке персональных данных (сайт собирает заявки) и сверить с юристом тексты политики и согласия.
- [ ] **Подтвердить документами утверждения на сайте:** запись в реестре Минтруда (аккредитация на обучение по охране труда), скидка 10 % для групп, выезд без доплаты, цифры «с 2014 года», «4 800 слушателей». Если чего-то нет, попросите разработчика убрать это с сайта.
- [ ] Пройти все 14 подразделов «Сведений» и проверить, что нигде не осталось вымышленных данных.
- [ ] Отправить пробную заявку и убедиться, что уведомление пришло.
