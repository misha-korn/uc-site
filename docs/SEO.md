# SEO и микрокопирайт — сайт учебного центра

Регион: Самара и Самарская область. Аудитория: специалисты по ОТ и кадровики предприятий (B2B, ~70 %), рабочие,
которые учатся за свой счёт (B2C). Тон: просто, конкретно, без канцелярита. Цены и сроки — на виду.

Переменные в шаблонах: `{org}` = `org.short_name` (фолбэк «Учебный центр»), `{city}` = «Самаре».
Длина: title ≤ 60–65 символов, description 140–160 символов. Бренд — в конце title через « — ».

Правила:
- `zayavka/`, `zayavka/spasibo/` — `<meta name="robots" content="noindex, follow">`, в sitemap не включать.
- `/obuchenie/?cat=` — `<link rel="canonical">` на саму себя с параметром (категории — посадочные страницы), прочие GET-параметры (utm и т. п.) — canonical без них.
- Пагинации нет. Admin — `Disallow: /admin/` в robots.txt.
- sitemap: `/`, `/obuchenie/`, все категории (`?cat=`), все опубликованные программы (`lastmod` не нужен), `/kontakty/`, `/sveden/` + 14 подразделов, `/politika/`, `/soglasie/`.
- Демо (SITE_DEMO=1): `<meta name="robots" content="noindex, nofollow">` на всех страницах — чтобы демо не конкурировало с реальным сайтом заказчика.

## 2. Структура заголовков

**Главная** — H1 (см. выше), подзаголовок-лид: «Лицензия, запись в реестр Минтруда, практика на тренажёрах. Теория — дистанционно, без отрыва от работы.»
- H2 «Направления обучения» → карточки категорий (H3 — название, текст — `short`, «{n} программ»)
- H2 «Популярные программы» → карточки (H3 — title, часы, срок, цена «от … ₽», кнопка)
- H2 «Почему выбирают нас» → `advantages` (H3)
- H2 «Как проходит обучение» → `steps` (нумерованный список, H3)
- блок `stats` (без заголовка или H2 визуально скрытый «Учебный центр в цифрах»)
- H2 «Частые вопросы» → `faq` (`<details><summary>` — вопрос, без H3)
- H2 «Оставьте заявку — перезвоним за 15 минут в рабочее время» → форма

**Каталог** — H1 «Программы обучения» (или имя категории) → фильтр-чипы → H2 по категориям (если без фильтра) → карточки H3.

**Программа** — H1 → лид (`short`) → ключевые факты (часы · срок · форма · цена · документ) → кнопка
- H2 «О программе» (`description`) · H2 «Кому подходит» (`audience`) · H2 «Модули программы» (`disciplines_list`, нумерованный)
- H2 «Практика» (если `practice`) · H2 «Документы программы» (ОП, учебный план, график, РПД, методички — ссылки)
- H2 «Записаться на обучение» (форма, программа предвыбрана) · H2 «Похожие программы»

**Сведения** — H1 = название подраздела, H2 — смысловые блоки (например, «Учредитель», «Места осуществления образовательной деятельности», «Лицензия»). Без H2 «Основные сведения» внутри «Основных сведений».

## 3. Микроразметка JSON-LD (schema.org)

Микроразметка itemprop по приказу № 1493 — отдельно (п. 7 CONTRACT.md). JSON-LD не конфликтует с ней: размещать в `<script type="application/ld+json">` в `<head>`.

- **Все страницы** (base.html): `EducationalOrganization` — `name` (full_name), `alternateName` (short_name), `url`, `telephone` (первый из phones), `email`, `address` (`PostalAddress`: `addressLocality` «Самара», `addressRegion` «Самарская область», `streetAddress`, `postalCode`), `foundingDate` (reg_date), `openingHours` по `work_time` вручную (например `"Mo-Fr 09:00-18:00"`), `hasCredential` не использовать.
- **Программа**: `Course` — `name`, `description` (short), `provider` → `{"@type":"EducationalOrganization","name":…}`, `courseCode` (code для ПО), `educationalCredentialAwarded` (document_issued), `timeRequired` (ISO 8601 по часам: `"PT40H"`), `inLanguage: "ru"`, `offers` → `{"@type":"Offer","price": price,"priceCurrency":"RUB","category":"Paid","availability":"https://schema.org/InStock"}`, `hasCourseInstance` → `{"@type":"CourseInstance","courseMode": "Blended" | "Onsite","location": адрес}`.
- **Каталог**: `ItemList` из `Course` (`url`, `name`, `position`).
- **Главная**: `FAQPage` из `faq` (Question/acceptedAnswer). Только если FAQ виден на странице.
- **Хлебные крошки** (программа, сведения): `BreadcrumbList`.
- **Контакты**: тот же `EducationalOrganization` + `geo` (если заказчик даст координаты).
- Не размечать `AggregateRating`/`Review` без реальных отзывов — санкции поисковиков.

Open Graph: `og:title` = title без бренда, `og:description` = description, `og:type` = website (программа — `article` не нужен), `og:image` = `static/img/og.png` 1200×630 (frontend), `og:locale` = ru_RU.

## 5. Микрокопирайт

### Кнопки (CTA)
| Место | Текст |
|---|---|
| Шапка | «Записаться» / телефон кликабельный |
| Hero главной | «Подобрать программу» (→ `/obuchenie/`) и вторичная «Оставить заявку» (→ якорь формы) |
| Карточка программы | «Подробнее» (вся карточка — ссылка) |
| Страница программы | «Записаться на обучение» |
| Отправка формы | «Отправить заявку» → в процессе «Отправляем…» (кнопка disabled) |
| Фильтр категорий | «Все программы» / название категории |
| Сведения — файл | «{doc.title} (PDF)» — подпись ссылки обязана объяснять назначение файла (п. 4 Требований), не «Скачать» |
| Версия для слабовидящих | «Версия для слабовидящих» / «Обычная версия» |
| Демо-форма | «В демо-версии форма не отправляется. На рабочем сайте заявка придёт вам на почту и в Telegram.» |

### Форма заявки — подписи и подсказки
- name: «Ваше имя» · placeholder «Иван»
- phone: «Телефон» · placeholder «+7 (___) ___-__-__»
- email: «E-mail (необязательно)» · placeholder «name@company.ru»
- organization: «Организация (если обучение оплачивает компания)»
- program: «Программа (необязательно)» · пустой пункт «Не знаю — помогите подобрать»
- comment: «Комментарий» · placeholder «Сколько человек, удобные даты, нужен ли выезд»
- consent: «Я даю [согласие на обработку персональных данных] и ознакомлен с [политикой]»
- Под кнопкой: «Перезвоним в течение 15 минут в рабочее время. Никакого спама.»

### Ошибки формы
| Поле / ситуация | Текст |
|---|---|
| name пусто | «Как к вам обращаться? Укажите имя.» |
| name > 120 | «Имя слишком длинное — сократите до 120 символов.» |
| phone пусто | «Укажите телефон — по нему мы свяжемся с вами.» |
| phone невалиден (не 10–15 цифр) | «Проверьте номер: нужно 10–15 цифр, например +7 900 123-45-67.» |
| email невалиден | «Проверьте e-mail: похоже, в адресе опечатка.» |
| comment > 2000 | «Комментарий слишком длинный — до 2000 символов.» |
| consent не отмечен | «Без согласия на обработку данных мы не сможем принять заявку.» |
| honeypot заполнен | (молча — показать страницу «Спасибо», заявку не сохранять или статус `spam`) |
| rate-limit | «Слишком много заявок с одного адреса. Попробуйте через 10 минут или позвоните нам: {org.phones}.» |
| CSRF / сессия | «Страница устарела. Обновите её и отправьте заявку ещё раз.» |
| Общая сводка над формой | «Проверьте поля, отмеченные красным.» |

### Успех
- `/zayavka/spasibo/` H1 «Спасибо, заявка принята». Текст: «Перезвоним в течение 15 минут в рабочее время ({org.work_time первой строкой}). Если удобнее — позвоните сами: {org.phones}.» Кнопки: «Вернуться к программам», «На главную».

### Прочее
- Плашка демо: «Демо-версия сайта. Организация и все данные вымышлены.»
- Дата обновления в сведениях: «Обновлено: {page_updated|date:"d.m.Y"}».
- Цена в карточке: «{price|intcomma} ₽» (не «от», если цена фиксированная); для групп: «Скидка 10 % для групп от 5 человек».
- Формат часов: «40 ак. ч» на карточке, «40 академических часов» на странице программы.
- Футер: «© {год} {org.short_name}. Лицензия № {license_number} от {license_date}.» + ссылки «Сведения об образовательной организации», «Политика обработки персональных данных».
